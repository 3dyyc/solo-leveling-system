# SOLO SYSTEM

Персональная RPG-система развития в стиле тёмного sci-fi / anime HUD. Проект рассчитан на мобильные устройства и последующую упаковку в Android APK.

## Сейчас реализовано
- Адаптивный неоновый интерфейс для ПК и Android.
- Плавное появление панелей и системные уведомления.
- Характеристики и распределение свободных очков.
- Уровни, EXP и награды за повышение уровня.
- Создание квестов и их завершение.
- Навыки, достижения и инвентарь.
- Журнал событий.
- Административные действия в прототипе: добавление квестов/навыков/предметов, выдача наград, имя игрока.
- Экспорт и импорт локального сохранения в JSON.
- Сохранение в localStorage текущего браузера.

## Запуск
Открой `index.html` в браузере или включи GitHub Pages для ветки `main`, папки `/(root)`.

## Важно
Это первая клиентская версия-прототип. Данные пока хранятся только в браузере конкретного устройства; они не синхронизируются между устройствами. Панель администратора не защищена серверной авторизацией и не должна считаться безопасной для публичного многопользовательского использования. Перед настоящим релизом добавим backend (например, Supabase), вход в аккаунт, серверные проверки прав, миграции базы данных и резервное копирование.

## План
